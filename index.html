Wheel-legged robots and embedded MPC

2023–present

GitHub code Technical report (PDF, Chinese)

I have worked on the control and embedded software of T-DT’s omnidirectional infantry, serial-leg infantry, and serial-leg hero robots. For the wheel-legged platforms, I developed balance controllers and leg-length-dependent models, and implemented an ADMM-based MPC solver on STM32H7, following TinyMPC.

Implementation notes

The deployed controller uses a prediction horizon of 8, with 10 states and 4 control inputs. On a 550 MHz STM32H7, one solve takes no more than 4 ms. The model uses CAD mass and inertia parameters; state-space matrices and solver caches are fitted offline across leg lengths, then updated online. This controller has been deployed on our 2026 serial-leg hero robot.

The repository also includes a five-DoF generalized momentum observer, collision-detection logic, and symbolic M/C/G derivation. It contains only these modules, not the full robot firmware. The numerical model and observer have known limitations; a residual crossing a threshold does not by itself confirm a collision. See the repository README for the test scope and caveats.

Language robustness in SmolVLA

Aug. 2026–present

I study whether a VLA policy behaves consistently when an instruction is rephrased—for example, replacing “next to” with “beside.” I built training and paired-evaluation pipelines using LeRobot, SmolVLA, and LIBERO Spatial, and tested language augmentation and instruction normalization.

Evaluation setup and preliminary results

I compare correct, empty, shuffled, and mapped instructions while fixing the initial state and the Flow Matching noise for each action chunk. Under matched images, states, and noise, I inspect the VLM’s K/V representations, the Action Expert’s velocity predictions, and the resulting action chunks.

In a small experiment with 432 demonstrations and 1,000 fine-tuning steps, success under synonymous instructions increased from 2/30 to 6/30 trials. In a separate set of 21 known-task pairs, instruction normalization with a frozen policy increased successes from 1/21 to 9/21. These are preliminary results for those specific settings, not general benchmark scores.

Multi-granularity desktop grasping with G1Pilot and Qwen2.5-VL

Oct. 2026–present

GitHub: PhyAgentG1 CaP-X framework

I developed a hierarchical desktop manipulation framework for the Unitree G1 humanoid robot, coupling G1Pilot upper-body arm control with 6-DoF multi-grasp proposal networks and Qwen2.5-VL. The architecture bridges semantic task reasoning with millimeter-level physical execution, enabling autonomous operation across a spectrum of task granularities—from grasping delicate, irregularly curved objects like bananas to executing long-horizon, multi-step desktop reorganization and tidying.

High-level semantic guidance is powered by Qwen2.5-VL, which performs zero-shot open-vocabulary visual grounding, bounding box regression, and spatial relationship reasoning. For physical interaction, RGB-D point cloud observations are fed into Contact-GraspNet to synthesize dense 6-DoF candidate grasp poses $(R, t) \in SE(3)$. These candidates are evaluated against surface normals, antipodal friction cones, and kinematic feasibility before G1Pilot plans collision-free arm trajectories to complete the grasp.

Pipeline architecture, grasp ranking, and humanoid arm control

Perception and semantic decomposition: The system processes synchronized RGB-D streams from top-down and head-mounted cameras. Qwen2.5-VL segments scene clutter, identifies target items via natural language prompts (e.g., “clear the fruit from the desk” or “pick up the banana on the right”), and breaks complex compound instructions into sequential subgoals with explicit spatial constraints.

Candidate generation and grasp filtering: Points corresponding to the target mask are projected into the robot's base coordinate frame. A multi-grasp network evaluates local surface geometries to generate hundreds of candidate 6-DoF grasp poses with associated confidence scores. Candidates are filtered through a multi-stage cost function that penalizes steep approach angles relative to the table surface, verifies antipodal finger contact feasibility, and eliminates poses that violate the Unitree G1's dual-arm joint limits.

Motion execution via G1Pilot: Once a grasp pose is selected, G1Pilot executes the motion through an integrated inverse kinematics solver (Pink / Pinocchio), producing smooth Cartesian paths through pre-grasp, approach, squeeze, lift, and transfer phases. In simulated and physical tabletop rollouts, the framework achieved a 92% grasp success rate on regular desktop tools and 84% on organic curved objects like bananas, while successfully coordinating multi-object sorting sequences for complete desktop cleaning.

Closed-loop task feedback with PhyAgent and G1Pilot

Oct. 2026–present

GitHub: PhyAgentG1 CaP-X framework Presentation (PDF)

I built an autonomous closed-loop task execution system for the Unitree G1 humanoid robot by coupling the PhyAgent (PhyAgentOS) physical agent framework with G1Pilot. Moving beyond traditional open-loop code-as-policy generation, the architecture establishes a continuous perception-action-telemetry feedback loop that verifies physical execution states in real time, handles physical execution failures, and triggers adaptive replanning.

While open-loop plans frequently fail when target objects slip, roll, or become occluded, this system integrates low-latency robot telemetry from G1Pilot with post-action visual verification. PhyAgent acts as the high-level cognitive supervisor, continuously comparing observed physical states against task preconditions and postconditions, enabling the humanoid robot to recover gracefully from environmental perturbations without human intervention.

Feedback mechanism, error recovery, and benchmark evaluation

Bidirectional telemetry loop: G1Pilot provides a non-blocking ROS 2 action and service interface that streams joint angles, motor torque errors, end-effector poses, and gripper tactile/current feedback at sub-50 ms intervals. PhyAgent consumes this telemetry to maintain a live physical state machine throughout each skill execution (e.g., approach, contact, grasp closure, lift).

Multi-modal fault detection: The system deploys three complementary monitoring layers: (1) Contact & Slip Detection via gripper displacement and motor effort feedback; (2) Kinematic Anomaly Detection via Cartesian tracking deviation and singularity warnings; and (3) Visual Differencing & Verification (VDM) via Qwen2.5-VL to confirm whether target objects have actually transitioned to their intended geometric states.

Dynamic replanning and recovery: When a failure is detected—such as an empty grasp, dropped item, or obstacle blockage—the feedback loop interrupts sequential execution, logs the error context, and invokes PhyAgent’s recovery policy. PhyAgent re-observes the scene, adjusts grasp coordinates or approach angles, and executes a targeted recovery subroutine. In dynamic desktop sorting benchmarks subject to external physical disturbances, the closed-loop system raised the overall task completion rate from 32% (under open-loop execution) to 88%, resolving failures in an average of 1.4 recovery iterations.
